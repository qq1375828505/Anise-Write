## 5. 今天踩的坑（别再踩）

1. **跨组合函数用状态要逐层传参**——不能闭包捕获上层局部变量（`showNovelStudio` 编译错，run #27 挂过一次）。
2. **Canvas 绘制层不能读 `@Composable` 状态**（`novelPalette` 是 @Composable getter）→ 先在外面取值。
2b. **漏 import `androidx.compose.foundation.Canvas`** → `Canvas` 与全部 `draw*` 图元 API 连锁 unresolved（21 条报错）；
   **`Float`/`Double` 混用**（`var cooling = 1.0`）也会一行错、满屏红。写完新文件先扫这两项。
3. **GitHub API**：更新 ref 要**完整 40 位 sha**（短 sha 422）；未挂 ref 的 commit 对象 GET 404；
   API 建的 commit 时间会被归一化 + 去掉末尾换行 → 与本地 sha 不同但 tree 一致，
   收尾用 `git fetch` + `git rebase origin/feature/penai`（会 skip 掉已应用的提交），**不要 force**。
4. **沙箱网络**：`github.com:443` 时断时续，`api.github.com` 通常通；主站连不上时用 Git Data API 推。
5. **挂载会瞬时丢文件**：8 个二进制资源曾"消失"，`git checkout --` 即恢复。先查挂载再怀疑代码。
6. **gitdir 改名三处同步**：`.git` 指针 + `config` 的 `core.worktree` + 脚本绝对路径。
7. **`rg` 不用 `-r`**；`file_write` 大文件拆段（≤8KB）。
8. **CI `cancel-in-progress: true`**：同分支再推一次会取消在跑的 run（cancelled ≠ 失败）。
9. **本地不能编译**（红线）：只能靠 `check_phase6.py` 静态自检 + CI 验证。
