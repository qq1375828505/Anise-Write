# 真机验收清单（Phase 8/9 前置）

> 用法：装 CI 产物后照着点一遍，逐条勾。**发现问题记在这一页**，修完再走一遍。
> APK 获取：Actions → 最新一次成功的 run → Artifacts → debug apk（full + fdroid 两个风味）。

---

## A. 应用身份与入口（改名回归）

- [ ] 启动器图标名称显示 **Anise Write**（不是 PenAi）
- [ ] 「设置 → 关于」里应用名正确
- [ ] AI 人格自述为 Anise Write（问它"你是谁"）
- [ ] 工具面板（+ 工具）里出现「**写作工作台**」入口
- [ ] 设置里有独立分组「**写作 → 模型组**」（不是挂在"模型配置"下面）

## B. 写作工作台（Phase 6a）

- [ ] 打开工作台：四个页签 **章节 / 资料库 / 关系图 / 统计**，底部栏 49dp 不透明、选中项为强调色
- [ ] 章节页：作品 → 卷 → 章节三级分组；行显示状态、字数、日期
- [ ] 章节行**左滑**露出「移动 / 改名 / 删除」三个动作
  - [ ] 移动：底部抽屉选目标卷，移完章节出现在目标卷末尾
  - [ ] 改名：输入框改标题，正文不受影响
  - [ ] 删除：二次确认后章节与正文一起消失
- [ ] 资料库页：八类资料分组，颜色图标区分；无资料时显示空态
- [ ] 统计页：三张数据卡（总字数/章节数/近 7 天）+ 概况分组
- [ ] 点章节进入编辑页：正文 19/32 显示，底部工具条有字数/字号/护眼/大纲/润色
  - [ ] 编辑后点「保存」，重新进入内容一致
  - [ ] 系统返回键先关编辑页、再关工作台

## C. 人物关系图 v2（Phase 6b）

- [ ] 关系图页有节点（人物卡：首字头像 + 姓名 + 身份），不是"只有名字和线"
- [ ] 边按**关系类型**分色（恋人/亲人/师徒/盟友/竞争/仇敌/上下级）
- [ ] 边的粗细随强度变化，强度高的边上有关系名
- [ ] 边上/节点间有方向箭头
- [ ] 同一势力的成员被虚线圈在一起，圈上有势力名
- [ ] 拖动画布可平移、双指可缩放
- [ ] 点节点：其邻居与相关边高亮，其余淡出，底部弹出详情卡（身份/目标/关系人）
- [ ] 右上角图例列出当前图里出现过的关系类型
- [ ] 空数据时显示空态引导

## D. 模型组 / 写作档（Phase 6.5）

- [ ] 设置 →「写作 → 模型组」打开列表页；预置三档（默认写作组 / 轻量组 / 审查组）
- [ ] 新建组 → 进入详情 → 改名称 → 保存
- [ ] 添加模型：选 provider → 拉取该 provider 的模型列表 → 选中加入
- [ ] 组详情可改角色（普通/默认组/轻量组），列表页徽标随之变化
- [ ] 「子代理模型」页：6 个子代理（大纲/人物/伏笔/润色/审读/一致性）各自可选组
- [ ] 委派行为验证（关键）：
  - [ ] 给某子代理钉一个组 → 触发该子代理的委派 → 结果 JSON 里 `model_used` 显示该组与模型
  - [ ] 不钉组时，委派请求带 `model_group=default_model` → 走默认组
  - [ ] 把钉的组成员删空（组不可用）→ 委派结果里出现 `model_group_unavailable: true` 与回落说明
- [ ] 删除组后，指向它的子代理绑定被解除（显示"跟随委派请求"）

## E. 工具侧（Phase 6c）

- [ ] `novel_move_chapter` 能换卷
- [ ] 两个工具都出现在工具清单里（AI 可调用）
