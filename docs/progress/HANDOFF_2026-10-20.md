### 4.1 `NovelAssetModels.kt` — 4 个类补 `referencedNames`
- 文件：`app/src/main/java/com/ai/assistance/quro/core/novel/asset/NovelAssetModels.kt`
- 报错：`LocationAsset`(217)、`AbilityAsset`(315)、`SettingAsset`(412)、`ReferenceAsset`(456) 四个类
  `does not implement abstract member: val referencedNames: List<String>`
- 原因：接口 `NovelAsset`（第 36–55 行）声明了 `val referencedNames: List<String>`；`CharacterAsset`(121)/`FactionAsset`(180)/`ItemAsset`(278)/`PlotlineAsset`(380) 已实现，这 4 个漏了
- 修法：在每个类的类体内（`override val type: AssetType get() = AssetType.XXX` 行之后）加：
  ```kotlin
  override val referencedNames: List<String> = emptyList()
  ```
  （这 4 个类没有结构化引用字段，给空列表即可；要增强可后续从正文提取）

## 8. 本环境的坑（换软件后照样有用）

1. **`/sdcard` 上 git 写不了**：Android FUSE 不支持 git 的「临时文件+rename」写 object（proot 的 link2symlink 会把临时文件变成符号链接），表现为 `unable to write file .git/objects/xx/...` 或 `failed to insert into database`。解法就是 §1 的分离 `.git`。
2. **git 全局配置已加** `safe.directory '*'`（Android 存储 UID 不同会报 dubious ownership）。
3. **proot 单条 exec 约 30 秒上限**，且后台进程（setsid/nohup）会在 exec 结束时被清理——长任务要么分步，要么立刻返回+轮询日志文件。
4. **apt 源被精简为仅 main**（为了把 `apt-get update` 压进 30 秒窗口），备份在 `/etc/apt/sources.list.bak`；git 2.43 已装入 proot。
5. **spawn_subagent 在本设备上不可靠**：8 次任务全部因 8KB 输出截断/轮数耗尽未产出结论；cluster_start 报「没有可用角色（模型不可用或预算耗尽）」；run_code 跑大脚本可能长时间无返回。**可靠路径：terminal exec 精确提取 + python 小步处理**。
6. **GitHub API 取 run id 要按 `run_number` 锚定**（见 §2）。
7. 统计分支产物时必须排除 `docs/progress/wip/` 快照目录（否则会误判文件存在性/漂移，已踩坑并沉淀经验）。
