## 6. 今天踩的坑（别再踩）

1. 🔴 **【编译杀手】KDoc / 块注释里写 `路径/*.md`**：`/` 紧跟 `*` 会被 Kotlin 当成**嵌套块注释开启**
   （Kotlin 块注释可嵌套），整个文件后半被吞 → `Unclosed comment` + 连锁
   `Unresolved reference`。**写注释避免 `/` 紧跟 `*`**（改成「`subagents` 下的 `*.md`」这类表述）；
   `check_phase6.py` 已加注释闭合检查，提交前必跑。
2. **沙箱 gitdir 会丢**：恢复三件套 = `cp .git.bak → /var/minis/workspace/anise-write-git`
   + 改 config 的 `core.worktree` 旧路径 + `git reset --mixed origin/main`（磁盘与远端 0 差异）。
3. **同一文件并发多次 `file_edit` 会写坏**（内容错位）：改文件一律用 **python 精确替换脚本**
   （每条 `count == 1` 断言 + 失败即中止），或单次单文件编辑。
4. **匿名拿不到 Actions 日志**（API 403 / 日志分片 404 / 网页要求登录）：必须带 `GITHUB_TOKEN` 走 API 下载 zip。
5. 沙箱 `github.com` 直连时断时续（`api.github.com` 稳定）：curl 重试 2-3 次通常能过。
6. 原有坑依旧（详见 HANDOFF_2026-10-22 §5）：跨组合函数用状态须逐层传参、Canvas 绘制层不读
   `@Composable` 状态、`rg` 不要用 `-r`、CI `cancel-in-progress`（cancelled ≠ 失败）、本地不编译（CI 是唯一编译器）。
