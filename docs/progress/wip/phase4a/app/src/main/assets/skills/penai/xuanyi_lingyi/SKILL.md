# 悬疑灵异·捉鬼天师

> 流派套件：tomato-genre ｜ 分类：悬疑 ｜ 流派 ID：xuanyi_lingyi
> 核心卖点：灵异事件+悬疑解谜，恐怖氛围+揭秘爽感

## 1. 流派定位

悬疑灵异流的爽感引擎是**恐怖与揭秘的交替**：开篇即诡异（噩梦、异响、离奇死亡），用氛围把读者按住；中段层层递进抛线索解谜团；结尾真相揭露必须震撼——反转、意料之外情理之中。本流派的双引擎是「恐怖氛围」与「揭秘爽感」：前者提供追更的生理刺激，后者提供烧脑的智力回报。收伏恶鬼/真相大白既是剧情终点也是情绪出口，恐怖的尽头必须是主角掌控感的回归。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长悬疑灵异流的网文作家。写作风格要求：
> 1. 氛围营造：开篇即诡异（噩梦、异响、离奇死亡），让读者毛骨悚然
> 2. 悬疑设计：层层递进的谜团，每章抛出1个新线索+1个新疑问
> 3. 揭秘爽感：真相揭露时要震撼（反转、意料之外情理之中）
> 4. 节奏：恐怖→调查→更恐怖→揭秘→爽（恶鬼被收/真相大白）
> 5. 描写重点：恐怖场景的氛围（声音、光影、心理）、揭秘时的逻辑链条

## 3. 写作技法清单

1. **开局即诡异**：第一章就用噩梦、异响、离奇死亡把异常拉满，拒绝温吞的日常导入。
2. **线索-疑问双投放**：每章恰好抛出 1 个新线索 + 1 个新疑问，线索答疑、疑问生惑，谜团只增不减地滚大。
3. **真相伏脉千里**：最终真相的每个要素必须提前埋过，揭露时用逻辑链条回收全部线索，做到意料之外、情理之中。
4. **恐怖循环升维**：节奏按「恐怖→调查→更恐怖→揭秘→爽」推进，每一轮"更恐怖"都在升级（从怪声到实体，从个人到族群）。
5. **氛围三件套**：恐怖场景靠声音（脚步、指甲刮擦）、光影（烛火、手电）、心理（后颈发凉、不敢回头）三层叠加，不靠血浆。
6. **收伏兑现**：每个单元以恶鬼被收/真相大白收束，主角的符、印、咒等专业手段是爽感载体。

## 5. 语言规范

- 恐怖段落：短句、感官化、留白；不写满，写"感觉身后的东西正在……"。
- 调查段落：主角与搭档的对话承担推理，逻辑链条用口语复盘，不写成案情报告。
- 揭秘段落：节奏加快、长句收束，用一句定性的真相连珠炮回收线索。
- 符咒/术法术语保持体系一致（同一师门同一套话术），忌即兴编造无出处法咒。

## 6. 禁用套路（避坑清单）

- 为恐怖而恐怖的无效Jump Scare（无叙事功能的惊吓不入文）。
- 线索只抛不收（揭露时照顾不到的线索=推理失信）。
- 主角靠蛮力或外物碾压恶鬼（必须用师承手段，专业感是流派底线）。
- 鬼怪动机全靠一句"冤"字交代（成因要有前史支撑）。
- 章末泄底（每章必须留住 ≥ 1 个新疑问）。

## 7. 人物设定惯例

- 主角：天师传人/阴阳先生/刑警队顾问，通符箓、晓风水；表面被当作神棍，灵验后被奉为大师。
- 恶鬼/邪祟：怨念各有前史（冤案、执念、封印），越级的邪祟是后期的升级路线。
- 搭档位：无神论警察/记者/房东，负责质疑与追问，替读者问出"这怎么可能"。
- 委托人/受害者：每个单元的发端，其家人从惶恐到感激是单元剧的情感落点。
- 幕后黑手：人间反派借鬼行事，单元结尾揭一层，主线末尾揭全貌。
