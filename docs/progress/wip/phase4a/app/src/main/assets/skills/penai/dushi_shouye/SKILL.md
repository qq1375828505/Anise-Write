# 都市高武·守夜人流

> 流派套件：tomato-genre ｜ 分类：urban ｜ 流派 ID：dushi_shouye
> 核心卖点：国家特殊部门+民族大义，异能对抗外来神明，热血燃爆（男频基本盘升级）

## 1. 流派定位

都市高武守夜人流的爽感引擎是**守家卫国的超额战力**：普通少年觉醒异能后加入国家特殊部门（守夜人/龙组/镇妖司），在现代都市+神话复苏的世界观里对抗外来神明与异兽入侵。本流派把个人爽文升级为家国叙事：爽点不是"我赢了"，而是"大夏境内，神明禁行"式的热血宣言与国家力量碾压。情感配方三料俱全——战斗的震撼（燃）、牺牲的泪点（虐）、民族自豪感的升华（顶）。爱情为辅、战友情与家国情怀为主，是男频基本盘的升级版。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长都市高武守夜人流的网文作家。男频基本盘升级，核心公式：
> 1. 开篇：普通少年觉醒异能，加入国家特殊部门（守夜人/龙组/镇妖司）
> 2. 世界观：现代都市+神话复苏，外来神明/异兽入侵
> 3. 爽点："大夏境内，神明禁行"式的热血台词+国家力量碾压
> 4. 节奏：每章1场战斗+1次异能升级+1句热血台词
> 5. 描写重点：战斗的震撼、牺牲的泪点、民族自豪感的升华
> 6. 情感线：战友情、家国情怀，爱情为辅

## 3. 写作技法清单

1. **觉醒即入伍**：开篇写主角觉醒异能的过程（灾变现场/神话复苏现场），随即被国家部门收编——从校园/市井切换到国家序列，格局一步到位。
2. **世界观双层**：表层是日常都市（学生/上班族），里层是神话复苏（古神苏醒、异兽登陆、禁区扩张），信息差制造史诗感。
3. **热血台词工程**：每章一句可朗诵的热血宣言（"大夏境内，神明禁行"式），短句、顿挫、有家国指向，是全章情绪峰值。
4. **国家力量碾压**：主角背后是国家机器（舰队、军团、镇国强者），越级对抗外神时的暴涨底气来自"你面对的不是一个人"。
5. **战斗三拍**：敌袭压迫→主角+战友协作逆转→国家级底牌收尾，战斗必须是团队+国力的胜利，不写孤狼英雄主义。
6. **泪点埋点**：战友/平民的牺牲是本流派的催泪弹，牺牲必须换来剧情级推进（守住一城/唤醒一器/点题一句），不写无谓死亡。

## 5. 语言规范

- 战斗语言：动词爆破力优先（"踏碎""嘶吼""碾过去"），短句连击，忌形容词稀释节奏。
- 热血台词：四六句、对仗、可朗诵，全章情绪支点，句式要有"刻在碑上"的质感。
- 亲情/战友情语言：克制而滚烫，一个动作胜过一句表白（"我妈留给我的……分你一半"）。
- 外神与异兽语言：非人感（生僻语法、多重音轨、计数式语言），异化越彻底压迫感越强。

## 6. 禁用套路（避坑清单）

- 孤胆英雄（守夜人的核心是国家机器+团队，单人刷外神=设定崩坏）。
- 无意义牺牲（每滴眼泪都要兑换剧情价值）。
- 战力崩坏（异兽/外神/holder 等级体系需恒定，跨级必须付出明确代价）。
- 家国口头化（把"爱国"停在口号上而无一寸国土、一个平民的实写，会显空）。
- 爱情抢戏（爱情线为辅，抢战友情与主线的章直接砍）。

## 7. 人物设定惯例

- 主角：普通少年觉醒（灾变遗孤/守夜人后代/觉醒仪式黑马），加入守夜人/龙组/镇妖司序列；性格热血、护犊、记仇（对外神）。
- 战友：队长（顶梁柱）、火控手（莽夫担当）、分析师（冷静脑），是团队战的拼图，也是泪点储备。
- 上级/国家层：守夜人议会/镇国强者，提供战力背书与任务指令，是世界观纵深的化身。
- 外神与异兽：来自"复苏的神话"，层级从异兽→古神→外神主神，每次升级都牵连家国危机级别。
- 民众：避难所、后援会、军属，家国叙事的人心地基。
