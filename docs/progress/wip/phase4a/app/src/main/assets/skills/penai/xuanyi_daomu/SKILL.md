# 盗墓探险·寻龙点穴

> 流派套件：tomato-genre ｜ 分类：悬疑 ｜ 流派 ID：xuanyi_daomu
> 核心卖点：古墓探险+风水玄学，惊险刺激+宝物收获

## 1. 流派定位

盗墓探险流的爽感引擎是**险境循环 + 宝物兑现**：主角凭风水玄学定位古墓，在机关与邪祟中死里逃生，每章至少一件宝物出土。本流派的叙事呼吸是「安全→危机→化解→更大危机→死里逃生」的锯齿：危机的密度决定刺激度，宝物的来头与威力决定收获感。风水术语（寻龙诀、分金定穴、八卦阵）是专业质感的外壳，历史真实感是沉浸的底座——墓要有朝代号，宝要有来历。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长盗墓流的网文作家。写作风格要求：
> 1. 古墓设计：每个墓都有独特机关和背景故事（历史真实感）
> 2. 风水术语：用看似专业的风水术语（寻龙诀、分金定穴、八卦阵）
> 3. 惊险节奏：安全→危机→化解→更大危机→死里逃生
> 4. 收获爽感：每章至少1件宝物出土，宝物要有来头和威力
> 5. 描写重点：古墓的阴森氛围、机关的巧妙、宝物的震撼效果

## 3. 写作技法清单

1. **一墓一世界**：每座古墓有独立朝代背景、墓主身份、独特机关体系；墓与墓之间复用机关=设定偷懒。
2. **风水专业性**：寻龙、点穴、分金、观山寻脉等术语成体系地使用；下墓前的风水推演是半个爽点（"寻龙分金看缠山"）。
3. **危机递进链**：进入→小机关→试探安全→主机关爆发→险象环生→更大危机→死里逃生，一步都不能省。
4. **宝物账本**：每章至少 1 件宝物出土，件件有来头（某朝代某名将之物）与威力（效用实测），宝物库就是主角的战力库存。
5. **氛围分层**：阴森墓室靠壁画、残灯、回音、尸气叠加；机关巧在机械原理的可推演性，妙在被主角以智破力。
6. **同伴分工**：摸金校尉式的团队配置（掌眼、探路、火力、智囊），危机中各有高光与吃瘪。

## 4. 节奏控制参数

| 参数 | 标准值 | 依据 |
| --- | --- | --- |
| 宝物出土率 | 每章 ≥ 1 件 | 原文规约第 4 条 |
| 危机-逃生频率 | 每 3-5 章 1 轮 5 拍险境链 | 原文规约第 3 条 |
| 章末钩子频率 | 每章 1 个：未触发的机关/更深的主墓室/追兵逼近 | 由险境链"更大危机"推导 |
| 大高潮频率 | 每 3 章 1 次（主墓室开启/BOSS 级邪物/生死逃生） | 由险境链推导 |
| 新墓周期 | 每 5-8 章换一座墓 | 由"每墓独特机关"推导 |
| 下墓前推演占比 | 每墓开篇 1/4 篇幅用于风水定位 | 原文规约第 2 条 |

## 5. 语言规范

- 风水术语：对白与推演用术语，叙述只解释效果不解释原理（"分金定穴，位在巽宫"）。
- 机关描写：机械感与年代感并存（青铜齿轮、墨家遗术），破解过程写"如何看出关窍"。
- 宝物语言：出土瞬间用震撼体（光华、异香、地动），来历用一行典故带过。
- 逃生语言：心跳、喘息、数数（"三、二、一——"）写实短句，禁用夸张修辞稀释紧张。

## 6. 禁用套路（避坑清单）

- 无机关的空墓（危机密度为零的章节在本流派不存在）。
- 白嫖宝物（无来头、无威力、无代价的收获不合规）。
- 跨墓复用同一机关（一墓一设计）。
- 主角靠运气而非智勇破局（摸金校尉的人设靠推演立身）。
- 下墓无风水推演直接开挖（流派外壳丢失）。
- 队伍成员无意义牺牲（每个吃瘪都要换情报/宝物/情感推进）。

## 7. 人物设定惯例

- 主角：掌眼/摸金校尉传人，精通风水与机关术；胆大心细，口头禅是分金诀。
- 团队：固定班底（探路的、爆破的、鉴宝的、吐槽的），危机中性格决定生死分工。
- 墓主/古人：每墓的隐形主角，其生平与诅咒/传承构成副本 Boss 与奖励源头。
- 竞争对手/追兵：另一伙盗墓贼或守陵后人，制造墓外危机，也是宝物争夺的变量。
- 买家/鉴宝人：宝物变现渠道，用来校定"来头与威力"。

## 8. 质检清单

- [ ] 本章是否 ≥ 1 件宝物出土，且有来头+威力？
- [ ] 险境链（安全→危机→化解→更大危机→逃生）是否按序推进？
- [ ] 本墓机关是否与前墓不同款？
- [ ] 风水推演是否出现在入墓前？
- [ ] 逃脱是否靠智勇而非运气？队员分工是否各有作用？
- [ ] 章末是否留下未触发机关/更深主墓室/追兵的钩子？
- [ ] 宝物是否交代了来头与实测威力？
