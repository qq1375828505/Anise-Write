## 1. 流派定位

女性悬疑刑侦流的爽感引擎是**专业碾压 + 秩序重建**：女性法医/刑警/心理学家凭专业能力破解完美犯罪，每案都有社会议题。本流派双线并进：刑侦线提供智力快感（发现尸体→调查线索→嫌疑人反转→真凶揭露），性别线提供情绪价值（打脸看不起女性的同事、拒绝被男性拯救）。平台重点扶持的根因：女性主角的专业主义+不恋爱脑，同时接住了"爽文读者"与"类型读者"两个池子。逻辑零漏洞是本流派的生死线——悬疑读者是最严苛的群体。

## 2. 番茄原文规约（全文平移）

> 1. 主角：女性法医/刑警/心理学家，专业能力强，不恋爱脑
> 2. 案件：连环杀人、失踪案、密室杀人，每案有社会议题

## 3. 写作技法清单

1. **专业主义主场**：破案关键必须由女性主角的专业能力给出（尸检结论、微表情读心、现场重建），英雄时刻是专业知识的高光。
2. **案件社会议题化**：每个案件背后挂一个社会议题（家暴、校园暴力、职场压迫、养老困境），真相之外留一层讨论空间，提升作品厚度。
3. **四拍刑侦链**：发现尸体 → 调查线索 → 嫌疑人反转 → 真凶揭露，节奏标准如流水线，读者吃透后追更体验极佳。
4. **性别偏见回收**：同事/上级/家属的"女性不适合一线"偏见，每次都要用一次专业打脸回收——偏见是刻意的钩子，打脸是义务。
5. **心理博弈戏**：审讯室对峙是主场戏，写微表情、话术陷阱、供词漏洞，不靠吼靠算。
6. **完美犯罪拆解**：凶手的"完美设计"必须比警方快一步，主角的最后一步只能赢在专业冷知识或人性盲区。

## 5. 语言规范

- 尸检/现场语言冷静精确（数据、术语、程序名），专业感=窒息感。
- 审讯语言克制、有压迫节奏，对话留白，供词要经得起复盘。
- 偏见语言真实刺耳（"女孩家别逞强"），不许软化——软化即减损打脸力度。
- 主角语言：简、准、少情绪词；情绪爆发只给受害者相关时刻。

## 6. 禁用套路（避坑清单）

- 靠男性拯救（刑警队长/顾问/男友破案=流派自杀）。
- 恋爱脑（暧昧让位于侦查，感情戏最多是背景低烧）。
- 案件逻辑漏洞（口供/监控/尸检报告/法律程序任何一环对不上即废稿）。
- 主角降智送线索（关键线索必须靠专业推导获得）。
- 议题摆设化（社会议题写不进人物动机=装饰性正确）。

## 7. 人物设定惯例

- 主角：法医/刑警/心理学家，业务顶尖，日常被结构性轻视；破案是她的语言。
- 搭档/上级：男性为主，初期偏见持有者，后期转为专业尊重；关系必须是战友非救赎。
- 凶手：高智商、有完整动机链、社会身份合理（家人/教师/医生），动机与案件议题互为表里。
- 受害者/家属：每案的入口与共情锚点，家属的追问推动主角。
- 同事群：技术组、法证组、片区民警，各有所长，是团队推理的拼图。
