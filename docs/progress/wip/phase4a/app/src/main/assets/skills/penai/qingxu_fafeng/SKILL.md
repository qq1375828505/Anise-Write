# 情绪发疯·怼人变强流

> 流派套件：tomato-genre ｜ 分类：urban ｜ 流派 ID：qingxu_fafeng
> 核心卖点：与其内耗自己，不如创死别人，系统奖励发疯行为（男女通吃，短视频引流神器）

## 1. 流派定位

情绪发疯流的爽感引擎是**被规训者的代理复仇**：社畜/学生被欺负到墙角时，绑定"发疯系统"——怼人、摆烂、掀桌子全部变强，道德绑架全部无效。本流派精准打击当代读者（尤其被社会规训的年轻人）的宣泄需求：现实里不敢发的疯，主角替他们发；现实里吃过的闷亏，主角当场喷回去。发疯语录自带短视频切片传播属性（钩子台词+炸裂反应），是本流派的天然引流引擎。爽感公式：压抑场景 → 发疯爆发 → 系统奖励 → 周围人震懾 → 全网玩梗。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长情绪发疯流的网文作家。男女通吃，短视频引流神器，核心公式：
> 1. 开篇：社畜/学生被欺负，绑定"发疯系统"，怼人/摆烂/掀桌子获得奖励
> 2. 系统机制：越发疯越强，道德绑架无效，创死所有人
> 3. 爽点：主角发疯语录成为全网热梗，所有人都怕她/他
> 4. 节奏：每章至少1个发疯名场面+1次系统奖励
> 5. 描写重点：发疯语录的冲击力、周围人震惊的表情、反派的崩溃
> 6. 情感共鸣：让被社会规训的读者产生强烈爽感

## 3. 写作技法清单

1. **欺负剧本标准化**：开篇把主角摁在最典型的规训场景里（领导画饼、父母重男轻女、同学霸凌、亲戚催婚），压迫越典型，发疯越解气。
2. **发疯系统记账**：怼人、摆烂、掀桌子均折算为奖励，系统公告体播报（"检测到发疯行为：掀桌，奖励……"），发疯有正反馈，人设永不回头的保证。
3. **语录工程**：每次发疯产出一句可传播金句（"我不发疯谁发疯？""你的饼画得比我命都长"），句子要短、要狠、要能被截图当弹幕。
4. **震惊环**：周围人震惊的表情是标配取景框——欺负者懵、旁观者傻、权威者讪，反应越大发疯越值。
5. **全网热梗化**：名场面被录屏传播→评论区玩梗→当事人社会性死亡，疯子语录成为公共资产，主角越疯越安全。
6. **反派崩溃递减**：反派从嚣张→错愕→崩溃→恐惧的姿态阶梯，一次比一次矮，读者越看越上瘾。

## 5. 语言规范

- 发疯语录用口语短句、反问句、排比句，禁止文绉绉（"朽木不可雕"式骂街没有传播力）。
- 压迫场景的语言写实（领导的官腔、父母的"为你好"），真实到读者认领。
- 系统播报用冷静公告体衬托发疯行为的荒诞，温差即喜剧。
- 反派崩溃写生理与社交细节（手抖、后退、赔笑），不写抽象描写。

## 6. 禁用套路（避坑清单）

- 主角内耗自省（本流派严禁"我是不是太过分了"式反思，道德枷锁由系统拆除）。
- 发疯无效（任何一次发疯都必须换来奖励或对方吃瘪，无效发疯=系统失信）。
- 道德绑架成功（亲戚/领导/网友的规劝在本书永远无效，这是流派承诺）。
- 发疯靠脏话堆砌（冲击力来自逻辑怼而非词汇量，脏话替代品是荒谬比喻）。
- 主角回归乖巧（发疯是单行道，回头的角色人设崩塌）。

## 7. 人物设定惯例

- 主角：长期被规训的社畜/学生，一朝绑定系统；发疯指数决定实力，性格从隐忍到放肆单线演进。
- 系统："发疯系统"，纯奖励机制无惩罚条款；偶尔用官方口吻拱火。
- 压迫者：领导、父母、亲戚、校霸、网络喷子，按"现实规训"模板批量生成。
- 围观者：同事、网友、亲戚群，是震惊表情与热梗发酵的土壤。
- 追随者：被主角替他们发过疯的路人，构成粉丝化的支持阵营。
