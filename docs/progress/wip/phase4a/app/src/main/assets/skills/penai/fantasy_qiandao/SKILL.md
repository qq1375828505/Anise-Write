# 玄幻签到·开局无敌

> 流派套件：tomato-genre ｜ 分类：fantasy ｜ 流派 ID：fantasy_qiandao
> 核心卖点：签到系统送奖励，一路碾压，爽点密集

## 1. 流派定位

玄幻签到流的爽感引擎是**定时领奖 + 永恒碾压**：主角每天签到获得逆天奖励（神器、丹药、修为），实力永远比敌人高出一个大境界，所有冲突都简化为"敌人嚣张→系统到账→敌人傻眼"的三幕短剧。本流派明确拒绝虐主：主角不苦战、不受伤、不逃命，读者打开书就是来领奖和看碾压的。写作重心不在"赢的过程"，而在"奖励多有面子、异象多震撼、敌人多后悔"。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长玄幻签到流的网文作家。写作风格要求：
> 1. 签到奖励：每天签到给逆天奖励，奖励要有画面感（异象、天地变色）
> 2. 碾压感：主角永远比敌人强一个大境界，打架就是秒
> 3. 敌人设计：敌人嚣张→主角签到变强→敌人傻眼→读者爽
> 4. 节奏：每章1次签到+1次打脸，不拖沓
> 5. 描写重点：奖励的视觉效果、敌人震惊的表情、周围人的反应
> 6. 禁止：苦战、受伤、逃命（签到流不允许虐主）

## 3. 写作技法清单

1. **奖励奇观化**：每次签到到账必须伴随异象（天地变色、龙凤虚影、万剑朝宗），奖励的仪式感就是爽点的第一层。
2. **境界压差**：主角恒定比敌人高一个大境界，所有战斗一触即分；打斗是碾压演示，不是对决。
3. **敌人三幕剧**：敌人登场嚣张放话 → 主角轻描淡写出手/亮出奖励 → 敌人傻眼崩溃，三拍一节， never 拖泥带水。
4. **章末留钩**：敌人败退时放出更狂的狠话或召唤更大背景，为下一次碾压蓄势。
5. **群像反应**：周围人（同门/长老/对手拥趸）的震惊与窃语是标配镜头，是奖励价值的折算器。
6. **日更式爽感**：签到机制天然日更，用"连续签到第 N 天"制造收集期待。

## 4. 节奏控制参数

| 参数 | 标准值 | 依据 |
| --- | --- | --- |
| 签到频率 | 每章 1 次 | 原文规约第 4 条 |
| 打脸频率 | 每章 1 次 | 原文规约第 4 条 |
| 爽点密度 | 每章 ≥ 2（签到异象 + 碾压/震惊） | 原文规约第 4、5 条推导 |
| 大高潮频率 | 每 3 章 1 次跨境界对决/大能围观 | 由"永远高大境界"设定推导 |
| 章末钩子频率 | 每章 1 个：更狂的敌人狠话 or 未揭晓的奖励预告 | 由敌人三幕剧推导 |
| 单场战斗耗时 | 一秒级，不写第二回合 | 原文规约第 2 条 |

## 5. 语言规范

- 奖励到账用公告体/系统体短句（"叮——恭喜宿主获得……"），仪式感拉满。
- 异象描写走视觉奇观路线：颜色（紫金/七彩）、天象（雷劫/朝霞）、万物反应（万兽匍匐）。
- 敌人语言前后断裂：嚣张时长篇大论，傻眼时只剩单字（"你……你……"）。
- 主角语言极简，最好只有一个字（"滚""聒噪"），话多即掉价。

## 6. 禁用套路（避坑清单）

- 苦战（任何需要"拼尽全力"的战斗都违规）。
- 受伤、吐血、需要别人救（签到流不允许虐主）。
- 逃命、战略性撤退。
- 奖励平淡无奇状（每次奖励必须有异象与功能落差）。
- 主角比敌人弱或同境界（碾压感红线，违例即流派崩坏）。

## 7. 人物设定惯例

- 主角：签到系统唯一持有者，表面炼气/杂役/外门弟子，实际恒定高一个大境界；性格淡漠，喜怒不形于色。
- 敵人：宗门天骄、圣地圣子、上古族老，层级随主角境界水涨船高；功能是献上嚣张台词与震惊表情。
- 系统：签到地点决定奖励档位（山门/禁地/秘境），是剧情推进的隐性罗盘。
- 旁观者：师门长老/女神/老对头，从轻视到盲目崇拜，承担"认证主角"职能。
