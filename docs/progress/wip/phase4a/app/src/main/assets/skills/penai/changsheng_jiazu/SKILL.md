# 长生家族·千年底蕴流

> 流派套件：tomato-genre ｜ 分类：urban ｜ 流派 ID：changsheng_jiazu
> 核心卖点：整个家族传承千年，层层揭秘家族实力，打脸各方势力（都市脑洞新贵）

## 1. 流派定位

长生家族流的爽感引擎是**千年底蕴的逐层解封**：现代普通青年突然曝光家族身份——"我家老祖活了五千年"。此后每章揭秘一层家族实力（产业、武力、人脉），每层都比上一层震撼，各方势力在"看不起→震惊→跪舔"的三段式里被打脸。本流派是都市脑洞新贵：把赘婿流的"身份揭露"升级为单位替换——不是主角一个人藏，是一个千年怪物在装普通人；爽感来源从个人逆袭变为"你面对的是五千年"的时间压强。反派层级从市井混混到地方豪强再到隐世家族，逐级撞上家族的不同历史切面。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长长生家族流的网文作家。都市脑洞新贵，核心公式：
> 1. 开篇：现代普通青年，突然曝光家族身份（"我家老祖活了五千年"）
> 2. 揭秘节奏：层层揭露家族实力（产业、武力、人脉），每层都比上一层震撼
> 3. 爽点：各方势力从看不起到震惊到跪舔的转变
> 4. 节奏：每章曝光1个家族秘密+1次打脸
> 5. 描写重点：家族长辈的逼格、隐藏产业的震撼、古老敌人的恐惧
> 6. 反派设计：从市井混混到地方豪强到隐世家族，层层升级

## 3. 写作技法清单

1. **千年钩子开篇**：第一章抛出"老祖活了五千年"的冰山一角（族谱第一页/一句酒后真言/一件旧朝遗物），主角的"普通"从此成为最大的悬念。
2. **揭秘阶梯**：家族实力分产业（经济）、武力（战力的历史）、人脉（与历代大人物的渊源）三条线，每章揭一层，层与层之间保持数量级差。
3. **逼格表演**：家族长辈出场即逼格拉满（一句"老夫汉时便在此地"、随手一件国宝），逼格是千年底蕴的直观化。
4. **三方态度曲线**：任何势力对主角的认知都走"看不起→震惊→跪舔"，且转向必须在本章或次章完成，不养隔夜仇。
5. **古老敌人恐惧**：被家族镇压过的古老存在（前朝余孽/隐世仇敌）的恐惧反应，反向认证家族分量。
6. **产业实体化**：隐藏产业写到可核查（一座山、一条街、一家百年老店），震撼来自具体物证。

## 5. 语言规范

- 逼格语言：长辈台词惜字如金、有历史纵深（"这规矩，是我定的"），不解释不炫耀。
- 震惊语言：反派与围观者的认知崩塌用短句与破折号外露（"你……你们家是那个……"）。
- 古老称谓体系（族老、守藏、外房）保持内部一致，忌随机编名。
- 当代线语言保持日常口语，与千年线形成代际反差。

## 6. 禁用套路（避坑清单）

- 一次揭完（层层揭秘是长效爽感，开篇交底=流派自杀）。
- 家族长辈全员隐世不出山（逼格需要持续供能，每 3 章至少一位长辈亮相）。
- 反派不付出代价（每章的看不起必须换成当章或次章的碾压）。
- 主角利用家族欺男霸女（底蕴用于碾压挑衅者，不用于作恶，读者代入感红线）。
- 秘密无物证（每个产业/人脉揭秘要有具体可感的东西落地）。

## 7. 人物设定惯例

- 主角：表面普通青年/小职员，家族边缘人；性格不卑不亢，习惯性地低估自己说话的分量。
- 老祖/族老：活了数千年的定海神针，逼格担当，多数时间沉睡，醒来即改局。
- 家族成员：守藏的、经商的、掌武的各支脉，初期对主角冷漠，随揭秘推进转为拱卫。
- 反派：市井混混（第一章）→地方豪强（中段）→隐世家族/古老敌人（后期），层级与家族揭秘深度匹配。
- 古老存在：曾被家族镇压的宿敌，其恐惧是家族实力的反向背书。
