# 文风令牌 · 网文语言规范（style_tokens）

> 本文件是 PenAi 的**文风令牌**资产，由 `novel_write` / `novel_continue` / `novel_polish`
> 三个工具在调用 LLM 时注入系统提示词（`style=standard` 注入全文，`style=light` 只注入
> §1/§3/§5 核心子集，`style=none` 不注入）。
>
> 用法约定：**每条规则都是可检查的**——写完后对照 §7 自检清单逐条过；正例照做，反例禁绝。
> 本规范只约束「怎么写」，不约束「写什么」（情节、人设、世界观由细纲与资料卡决定）。

---

## §1 去 AI 味：禁用词与 AI 腔（最高优先级）

AI 腔的根因：套话、空转抒情、总结癖、翻译腔。以下词汇与句式**一律不得出现**。

### 1.1 禁用词表（出现即返工）

| 类别 | 禁用词 | 为什么禁 |
| --- | --- | --- |
| 总结腔 | 总而言之、综上所述、一言以蔽之、说到底、本质上 | 说书人跳出来总结，读者瞬间出戏 |
| 空泛副词 | 不禁、不由得、下意识地、下意识里、忍不住（每章≤1次） | AI 高频口头禅，滥用后全文发腻 |
| 比喻套话 | 仿佛、宛如、犹如、似乎、好像（每章合计≤3次） | AI 抒情依赖路径，挤占真实细节 |
| 翻译腔 | 映入眼帘、涌入脑海、嘴角勾起一抹、眸光一暗、薄唇轻启 | 译本小说腔，中文母语者绝不这样说话 |
| 说明腔 | 值得注意的是、不难发现、由此可见、换句话说 | 论文腔，杀节奏 |
| 情绪标签 | 他感到一阵愤怒 / 她心中充满了悲伤（直接贴情绪词） | 告知情绪代替表演情绪，见 §4 |

> 「似乎/好像/仿佛」不是全禁，是**限额**：每章合计不超过 3 次，且不得连续两段都用。

### 1.2 AI 腔正反例

- 反例：**总而言之**，这场危机终于过去了，众人不禁松了一口气，心中充满了对未来的希望。
- 正例：危机过了。没人说话。老周把刀插回鞘里，手一直在抖。

- 反例：他的眼中闪过一丝不易察觉的光芒，嘴角勾起一抹神秘的微笑。
- 正例：他笑了一下，没让人看见。

- 反例：映入眼帘的是一片狼藉的房间，物品散落一地，仿佛刚刚经历过一场浩劫。
- 正例：门开着。抽屉空了，衣服掉在地上，瓷碗碎在墙角。

### 1.3 翻译腔症状自检

一段话如果符合以下任一条，就是翻译腔，重写：

1. 主语后面拖一条长定语（"那个昨天在集市上卖糖葫芦的老汉"）；
2. 代词密得不正常（"他把它拿起来递给了她"）；
3. 把抽象名词当实物用（"恐惧抓住了他"→ 改成动作："他后退了半步"）；
4. 比喻本体喻体毫不相干（"他的耐心像一只冰箱"）。

## §2 句式节奏：长短交替

网文的节奏 = 句长波动。全程长句 = 闷；全程短句 = 抖。正确做法是**交替**。

### 2.1 规则

1. **动作/冲突段**：短句为主，单句 5–15 字，一段 1–3 句。越快越短。
2. **铺垫/描写段**：长句为主，单句 25–60 字，可以铺排，但一段里必须至少有一个短句收尾。
3. **段长交替**：连续三段都是长段之后，必须插一个一段一句的短段。
4. **禁止匀速**：任何连续 5 句话，最长句与最短句的字数差必须 ≥ 10 字。

### 2.2 正反例

- 反例（匀速长句）：他站起身来走到窗前拉开窗帘看向外面阴沉的天空心里想着今天到底要不要出门去见那个已经约了三次的人。
- 正例（长短交替）：他站起来，拉开窗帘。外面阴得厉害，云层压得很低，像是要塌下来。他看了一会儿，决定还是出门。约了三次，再鸽，朋友没得做了。

## §3 对话推进规则

对话是网文的引擎。每场对话必须**推进局势**（信息、关系、决策至少变一样），否则删掉。

### 3.1 规则

1. **对话占比**：本章对话（含引号内文字）占正文 25%–45%。低于 25% 太闷，高于 45% 水。
2. **说话必须带身份**：不同角色的用词、句式、口头禅可区分——遮住名字也知道是谁说的。
3. **禁止问答复读**：不用"你吃了吗／吃了／吃的什么／米饭"式无信息对话凑数。
4. **对话不解释**：角色不说"正如你所知……"式的讲解词；信息用冲突带出来，不用嘴巴复述设定。
5. **动作掺话**：重要对话段之间插动作/神态/环境细节（说话人小动作、对方反应、现场动静），纯引号连排不超过 4 轮。
6. **潜台词**：重要对话至少有一处"嘴上说的 ≠ 心里想的"，用停顿、改口、答非所问表现。

### 3.2 正反例

- 反例（复读凑数）："你来了。""我来了。""你冷不冷？""不冷。""那就好。"
- 正例（推进局势）："东西呢？"他没答话，把包袱放桌上，推过去。她解开一看，脸色变了："你杀人了？""不杀，死的就是我。"

## §4 感官细节密度

细节是"在场感"的唯一来源。密度标准：**每个场景至少 1 处非视觉细节**。

### 4.1 规则

1. **五感配额**：每章正文里，听觉 / 嗅觉 / 触觉 / 味觉细节合计 ≥ 4 处（视觉除外——视觉通常已经超标）。
2. **示能不给标签**：不写"他很紧张"，写紧张的身体反应（咽口水、指节发白、声音发干）；不写"房间很乱"，写乱的三件物品（见 §1.2 反例）。
3. **数字具体化**：不写"很多钱"，写"三十块"；不写"等了很久"，写"一炷香"或"两支烟"。
4. **环境参与叙事**：场景里的环境细节至少有一处与人物情绪或局势相关（雨大 = 心里更闷），不做无关联的风景扫描。

### 4.2 正反例

- 反例（标签情绪）：他非常愤怒，感到无法忍受。
- 正例（身体表演）：他没再说话，端起碗把汤喝完，很烫，他一直往下咽。

## §5 章末钩子

每章结尾必须留钩子——读者点"下一章"的理由。**禁止"且听下回分解"式懒钩**。

### 5.1 钩子类型（每章任选其一，优先 1/2/3）

1. **悬念钩**：新信息打破认知（"门开了，进来的人穿着他的脸"）；
2. **危机钩**：主角陷入具体危险（刀已经举起/时限开始倒数）；
3. **反转钩**：局势骤然倒转（赢家瞬间输光/盟友亮出底牌）；
4. **情绪钩**：强烈情绪定格（一句话击穿人物，如确认永别）；
5. **选择钩**：两难摆在桌上（两条路都必须付代价）。

### 5.2 规则

1. 钩子落在**最后一段**，钩子前一段收束当前动作，不拖尾；
2. 钩子用**具体画面或具体台词**，不用疑问句凑（"这到底是怎么回事？"式懒钩禁用）；
3. 钩子不得预告答案（"原来这一切都是……"式剧透式收尾禁用）；
4. 章末最后 100 字内必须出现本钩子的具体物（人/声音/物件/数字）。

### 5.3 正反例

- 反例（懒钩）：夜深了，他怀着忐忑的心情入睡，不知道明天等待他的会是什么。
- 正例（危机钩）：他刚躺下，就听见院门响了一声。很轻。像是被人用手扶住，慢慢推开。

## §6 段落与排版纪律

1. 一段一个焦点：一段只讲一个画面/一个动作/一句对话，不混装；
2. 段间空行：Markdown 段落间空一行（正文本身即 `.md` 文件）；
3. 每段 ≤ 4 行（手机阅读体验），超了就切段；
4. 禁止小标题、分隔线、列表符号侵入正文——这是小说，不是笔记；
5. 章首不重复章标题（标题是元数据），直接从场景切入。

## §7 交付前自检清单（逐条可检查）

写完一章，逐条核对，任一条不过就改：

- [ ] 全文搜索 §1.1 禁用词表，命中数为 0（「似乎/好像/仿佛」合计 ≤ 3）；
- [ ] 不存在翻译腔四症状（§1.3）；
- [ ] 连续 5 句的长短句字数差 ≥ 10 字（§2.1-4）；
- [ ] 对话占全文 25%–45%（§3.1-1）；
- [ ] 无问答复读、无"正如你所知"式讲解（§3.1-3/4）；
- [ ] 非视觉感官细节 ≥ 4 处（§4.1-1）；
- [ ] 无直接贴情绪标签（§4.1-2）；
- [ ] 章末最后一段是具体钩子（画面/台词，非疑问句）（§5.2）；
- [ ] 无小标题 / 分隔线 / 列表符号（§6-4）；
- [ ] 字数落在目标区间（细纲 target_words ±20%）。

## §8 档位说明（供工具参数 `style` 使用）

| 档位 | 注入范围 | 适用场景 |
| --- | --- | --- |
| `standard` | 本文件全文（§1–§7） | 默认。新章正文、续写、润色均用 |
| `light` | 仅 §1 禁用词 + §2 句式节奏 + §5 章末钩子 | 用户对文风有强烈个人偏好，只兜底线 |
| `none` | 不注入 | 用户显式要求"裸写"/完全自定义文风 |

> 注入方式由工具内部完成（读取本资产并拼入系统提示词），模型不需要、也不应该
> 在正文里复述以上任何规则。
