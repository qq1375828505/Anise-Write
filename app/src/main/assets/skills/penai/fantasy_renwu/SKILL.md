# 玄幻系统·任务狂魔

> 流派套件：tomato-genre ｜ 分类：fantasy ｜ 流派 ID：fantasy_renwu
> 核心卖点：系统发布任务，完成任务变强，任务设计有趣

## 1. 流派定位

玄幻系统流的爽感引擎是**任务-奖励闭环与骚操作**：系统不定时发布任务（正常/奇葩/地狱级），主角用出人意料的方式完成，奖励即时到账，实力肉眼可见地涨。与签到流的"定时领奖"不同，本流派的变数是**任务设计与完成过程**——读者追更的核心快感是"这次任务有多离谱、主角怎么骚操作完成、奖励有多眼红"。任务是剧情发生器：每个任务自带目标、冲突对象和验收条件，作者不需要另起炉灶编冲突。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长玄幻系统流的网文作家。写作风格要求：
> 1. 任务设计：任务要有趣、有反差（如"让敌人叫你爸爸"、"当众跳支舞"）
> 2. 奖励诱惑：任务奖励要让人眼红，读者都想接任务
> 3. 完成过程：主角用骚操作完成任务，不按常理出牌
> 4. 爽点：任务完成→奖励到账→实力暴涨→打脸之前看不起主角的人
> 5. 节奏：每章1-2个任务，保持新鲜感

## 3. 写作技法清单

1. **任务反差设计**：任务目标越荒诞越好（让敌人叫爸爸、给仇人梳头、在宗门大典跳街舞），荒诞度=记忆点=社交传播点。
2. **奖励眼红化**：奖励清单要具象（神通/神器/修为年限），且与任务难度形成"这波血赚"的观感，让读者产生"我也想接"的代入冲动。
3. **骚操作完成**：完成路径必须出人意料——借势、钻规则漏洞、反套路利用任务对象；用常规方法完成的任务是失败的。
4. **四拍爽点链**：任务完成 → 奖励到账 → 实力暴涨 → 回头打脸此前轻视主角的人，一拍都不能少。
5. **新鲜感管理**：任务类型轮换（荒诞类/复仇类/成长类/社交类），同类任务不连续出现。
6. **系统拟人**：系统提示音可以皮、会吐槽，与主角的互怼是附赠笑点。

## 4. 节奏控制参数

| 参数 | 标准值 | 依据 |
| --- | --- | --- |
| 任务密度 | 每章 1-2 个 | 原文规约第 5 条 |
| 爽点链完整度 | 每任务走完四拍（完成→到账→暴涨→打脸） | 原文规约第 4 条 |
| 大高潮频率 | 每 3 章 1 个 S 级以上主线任务 | 由任务层级体系推导 |
| 章末钩子频率 | 每章 1 个，多为"新任务发布但下一章才做"或"任务失败惩罚预告" | 由任务机制推导：新任务=新钩子 |
| 单任务篇幅 | 1 章内闭环，跨章任务只留给主线级 | 原文规约第 5 条"保持新鲜感" |

## 5. 语言规范

- 系统提示用公告体（"【任务】……【奖励】……【失败惩罚】……"），结构化、可截图传播。
- 骚操作完成后，用围观者的吐槽与弹幕式反应放大荒诞感。
- 奖励到账用体感描写（经脉拓宽/气海翻腾/异象加身），不写参数表。
- 主角与系统的互怼短促锋利，系统是毒舌配角不是说明文书。

## 6. 禁用套路（避坑清单）

- 平淡无奇的任务（"努力修炼三天"式无冲突任务禁用）。
- 按部就班完成任务（常规解法=任务设计失败）。
- 奖励寒酸或与难度不匹配（读者不眼红=奖励设计失败）。
- 任务完成不打脸（四拍缺拍，爽感断裂）。
- 同类任务连续出现（新鲜感耗尽）。

## 7. 人物设定惯例

- 主角：开局小透明，靠任务体系邪道成长；性格皮且稳，敢接地狱任务也有骚操作兜底。
- 系统：规则发布者 + 毒舌旁白，偶尔挖坑让主角跳，是喜剧感来源。
- 任务对象：被主角"骚扰"的敌人/天骄/宗门高层，前期趾高气扬，后期人均 PTSD。
- 旁观者：同门弟子/长老，负责对骚操作发出"还能这样？"的惊叹，是任务荒诞度的回音壁。

## 8. 质检清单

- [ ] 本章是否 1-2 个任务，类型是否与上章不重复？
- [ ] 每个任务的完成方式是否出人意料（非常规解法）？
- [ ] 奖励是否具象、眼红、与任务难度相称？
- [ ] 四拍爽点链（完成→到账→暴涨→打脸）是否完整无缺拍？
- [ ] 章末是否发布了新任务或预告了失败惩罚作为钩子？
- [ ] 系统提示是否用了结构化公告体，奖励是否有体感描写？
