# 穿越年代·改革开放

> 流派套件：tomato-genre ｜ 分类：穿越 ｜ 流派 ID：chuanyue_niandai
> 核心卖点：穿越七八十年代，抓住时代机遇发家，年代感+爽感

## 1. 流派定位

穿越年代文的爽感引擎是**先知先觉的时代红利**：主角穿越回七八十年代，踩着改革开放的鼓点进货、倒腾、办厂，把粮票、布票、万元户这些时代符号变成个人财富的刻度。本流派的双支柱是「年代感」与「赚钱爽」：前者负责真实与沉浸（生活细节准确还原），后者负责追更动力（赚钱速度让读者爽）。打脸对象固定为看不起主角的亲戚、邻居、领导——他们代表旧眼光，主角代表新机遇。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长穿越年代文的网文作家。写作风格要求：
> 1. 年代细节：准确还原七八十年代的生活细节（粮票、公社、万元户）
> 2. 时代机遇：主角抓住改革开放机遇（倒腾、做生意、办厂）
> 3. 打脸对象：看不起主角的亲戚、邻居、领导
> 4. 节奏：每章1个商机+1次打脸，赚钱速度让读者爽
> 5. 描写重点：钱的面额、物资的珍贵、众人从鄙视到巴结的转变

## 3. 写作技法清单

1. **年代细节考据**：粮票、公社、供销社、的确良、三大件等时代符号准确出现；细节越真实，红利兑现越有底气。
2. **商机考古**：主角的每次出手锚定一个真实历史机遇（价格双轨制、南下倒腾、乡镇企业、股票认购证），先知感=爽感地基。
3. **三重打脸对象**：亲戚（嫌主角不务正业）、邻居（嚼舌根）、领导（卡证明），每人固定负责一类轻视，被赚钱速度逐个碾过。
4. **账目奇观**：钱的面额（十元大钞/一沓钞/一皮箱）、物资的珍贵（一台电视机=全村的盛事）用物质稀缺性折算财富冲击力。
5. **态度反转**：从鄙视到巴结的转变要写过程——先是窃喜看笑话，再是试探接触，最后是排队讨好。
6. **商机-打脸双章**：每章恰好 1 个商机 + 1 次打脸，赚钱本身就是爽点，打脸是加速器。

## 4. 节奏控制参数

| 参数 | 标准值 | 依据 |
| --- | --- | --- |
| 商机密度 | 每章 1 个 | 原文规约第 4 条 |
| 打脸频率 | 每章 1 次 | 原文规约第 4 条 |
| 爽点密度 | 每章 ≥ 2（商机兑现 + 态度反转） | 原文规约第 4、5 条推导 |
| 财富量级跃迁 | 每 3 章翻一个数量级（元→百元→万元户） | 由"赚钱速度让读者爽"推导 |
| 大高潮频率 | 每 3 章 1 次大规模商机（办厂/大宗倒腾） | 由时代机遇层级推导 |
| 章末钩子频率 | 每章 1 个：新政策风向/下一单生意/反派告状 | 由经商结构推导 |

## 5. 语言规范

- 年代语体：对话带年代口语（"万元户""投机倒把""个体户"），叙述语言保持现代网文的爽利，形成"叙述现代、对话年代"的混合质感。
- 数字具象化：金额写面额与实物购买力（"一张一百块，能买半头猪"），不写抽象财富值。
- 打脸语言：亲戚邻居的酸话要土、要具体；主角的反击用事实（挣了多少）不用辩驳。
- 政策引述要克制（一句风向带过），不成篇抄文件。

## 6. 禁用套路（避坑清单）

- 年代硬伤（出现时代不存在的物事/称谓，读者会抓虫，直接判伪）。
- 主角靠异能/系统赚钱（本流派唯一金手指是先知，外挂越少年代味越正）。
- 打脸拖到下章（每章 1 次，当章兑现）。
- 对仇敌道德说教（用收入差距和排队巴结说话）。
- 商机无过程（一句"我南下了一趟"就赚几千=年代版白嫖）。

## 7. 人物设定惯例

- 主角：穿越者，初始身份多为知青/待业青年/农村子弟；第一笔生意从家门口开始。
- 亲戚：吸血长辈+嫉妒兄弟姐妹，早期主要压迫源，后期排队巴结。
- 邻居/街坊：情报网兼吃瓜团，负责扩散"发财了"的声量。
- 领导/干部：从卡证明、扣帽子到主动扶持，态度曲线就是主角社会地位曲线。
- 时代配角：货郎、供销社主任、南下列车上的同行，是商机的载体。

## 8. 质检清单

- [ ] 本章是否恰好 1 个商机 + 1 次打脸？
- [ ] 年代符号（票证/称谓/物价）是否准确、 ≥ 2 处细节？
- [ ] 商机是否有过程（怎么发现、怎么跑、风险是什么）？
- [ ] 收入是否用面额+购买力双重量化？
- [ ] 打脸对象的鄙视→巴结曲线是否在推进？
- [ ] 章末是否留了新政策/新订单/新麻烦作为钩子？
- [ ] 全章是否无超时代外挂、无年代硬伤？
