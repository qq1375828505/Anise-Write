# 玄幻无敌·横推诸天

> 流派套件：tomato-genre ｜ 分类：fantasy ｜ 流派 ID：fantasy_wudi
> 核心卖点：开局满级，一路横推，绝对无敌

## 1. 流派定位

玄幻无敌流的爽感引擎是**绝对力量的花式展示**：主角开局即满级，全书不存在成长曲线，剧情推进完全依赖"谁来挑战→怎么被吊打"的循环。看点是主角吊打各路天才、老祖、神明的姿势多样性，敌人越强越嚣张，被打脸时越爽。本流派与签到流共享"不虐主"铁律，但更进一步：连签到领奖的过程都省了，主角就是规则本身，每一次出手都是对既有力量秩序的重新确认。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长玄幻无敌流的网文作家。写作风格要求：
> 1. 无敌设定：主角开局就是最强，不需要修炼升级
> 2. 看点：看主角怎么花式吊打各路天才、老祖、神明
> 3. 敌人设计：敌人越强、越嚣张，被打脸时越爽
> 4. 打斗：一招秒，重点写敌人从不可一世到怀疑人生的过程
> 5. 节奏：每章至少1个强敌+1次碾压
> 6. 禁止：苦战、受伤、需要别人救（无敌流不能虐主）

## 3. 写作技法清单

1. **零成长设定**：主角开局即战力天花板，全书无修炼线、无升级线；所谓"变强"只是揭示他原来还能更强。
2. **花式吊打**：同一场碾压不能重复姿势——这次弹指灭杀，下次言语镇杀，再一次放对方大招再原路奉还，姿势库要轮换。
3. **敌人放大器**：敌人的强度与嚣张度决定单章爽感上限；每章新登场的敌人必须在"隐居老祖/上古邪魔/真神转世"这一量级持续加码。
4. **怀疑人生写尽**：打斗结果一句话交代，篇幅全部给敌人从"不可一世"到"怀疑人生"的心理崩塌过程。
5. **章末升级**：本章被碾者临死放出其背后更大存在的名号，把横推目标指向下一层诸天。
6. **地图横推进**：以"横推诸天"为结构，每换一张地图（下界/仙界/神界）反派升一级，碾压同步升一级。

## 4. 节奏控制参数

| 参数 | 标准值 | 依据 |
| --- | --- | --- |
| 强敌登场频率 | 每章 ≥ 1 个 | 原文规约第 5 条 |
| 碾压频率 | 每章 ≥ 1 次，一招秒 | 原文规约第 5、4 条 |
| 爽点密度 | 每章 ≥ 2（敌人嚣张展示 + 碾压打脸） | 原文规约第 5 条推导 |
| 大高潮频率 | 每 3 章 1 次老祖/神明级对决 | 由敌人层级递进推导 |
| 章末钩子频率 | 每章 1 个：败者召唤更大背景 or 新地图入口开启 | 由横推诸天结构推导 |
| 吊打姿势重复率 | 相邻两章禁止同姿势 | 原文规约第 2 条"花式" |

## 5. 语言规范

- 敌人战前语言极端自信，最好带围观者的吹捧伴奏（"此子天生异象，必成仙王"），与结局形成反讽。
- 碾压动作只用一字命名（镇、碾、焚、镇杀），动作越短威能越重。
- 主角语言：言出法随级，对话即是规则宣告，多用于判对方死刑而非解释。
- 心理描写配额全给敌人：震惊→恐惧→怀疑人生→绝望，四态递进不跳步。

## 6. 禁用套路（避坑清单）

- 苦战、受伤、需要别人救（无敌流不能虐主，红线中的红线）。
- 主角修炼升级情节（与"开局最强"直接冲突）。
- 敌人靠话术/规则/背景让主角吃瘪后全身而退（每一章的嚣张必须以当章或次章的碾压兑现）。
- 重复的同款吊打姿势（读者为姿势付费）。
- 主角对敌人解释自己的境界（无敌者不需要自证）。

## 7. 人物设定惯例

- 主角：无成长线，身份是行走的谜（被误认为扫地僧/后辈/凡人），性格淡漠慵懒，出手只因被聒噪。
- 敌人班底：下界天骄→隐世老祖→上古邪魔→诸天神明，与地图层级严格对应。
- 配角阵营：盲从者（无脑吹主角）与质疑者（被反复打脸），承担弹幕与惊叹职能。
- 背景势力：被打脸者的靠山，一轮横推换一茬，旧势力的恐惧是新势力的投名状。
