# 天命反派·背景编辑流

> 流派套件：tomato-genre ｜ 分类：fantasy ｜ 流派 ID：tianming_fanpai
> 核心卖点：穿越成反派，能编辑自己和他人的背景设定，收割天命之子（玄幻常青树）

## 1. 流派定位

天命反派流的爽感引擎是**设定层的降维操作**：主角穿越成即将被主角打脸的反派，绑定"背景编辑系统"——能编辑自己和他人的背景设定（凡人→王侯→帝族→仙神）。当原主角在剧情层努力时，本主角在设定层改设定：你以为是逆天改命，我改的是你的命格档案。爽点=背景每升级一层，原主角的自信就崩塌一分。本流派还解决了"反派主角"的代入难题：不是纯恶的反派，而是有脑子、有手段、让读者喜欢的反派——"与全世界为敌，但全世界活该"。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长天命反派流的网文作家。玄幻常青树，核心公式：
> 1. 开篇：穿越成即将被主角打脸的反派，绑定"背景编辑系统"
> 2. 系统机制：能编辑自己和他人的背景设定（凡人→王侯→帝族→仙神）
> 3. 爽点：不断升级自己的背景，让原主角从看不起到绝望
> 4. 节奏：每章编辑1次背景+收割1个天命之子
> 5. 描写重点：背景曝光时的天地异象、原主角的怀疑人生、系统的骚操作
> 6. 反派魅力：不是纯恶，是有脑子的反派，让读者喜欢

## 3. 写作技法清单

1. **逆穿越定位**：开篇即"剧本已知"——主角清楚地知道自己是谁、原剧情怎么走、死期是哪天；先知感+危机感开局，拒绝废柴逆袭模板。
2. **背景编辑操作**：每次编辑都要写出"改前→改后"的档案对比（出身、师承、跟脚），编辑是技术活，不是念咒。
3. **编辑他人**：除了自编，也给原主角身边的人改背景（把他的靠山改成自己的暗棋），攻防一体。
4. **天地异象曝光**：每次背景升级必须伴随天地异象（紫气东来/星象重排），设定变动是世界认证的大事。
5. **原主角崩塌**：原主角每章目睹一次自己的"已知情报"失效，从自信→疑惑→怀疑人生→绝望，其表情就是本流派的进度条。
6. **收割节奏**：每章收割 1 个天命之子——收服、夺取气运或策反其阵营，收割是编辑的兑现。

## 4. 节奏控制参数

| 参数 | 标准值 | 依据 |
| --- | --- | --- |
| 背景编辑 | 每章 1 次 | 原文规约第 4 条 |
| 天命之子收割 | 每章 1 个 | 原文规约第 4 条 |
| 爽点密度 | 每章 ≥ 2（异象曝光 + 原主角崩塌） | 原文规约第 4、5 条推导 |
| 大高潮频率 | 每 3 章 1 次跨档编辑（凡人→王侯→帝族→仙神级跳） | 由背景层级体系推导 |
| 章末钩子频率 | 每章 1 个：原剧情新节点/更大气运者登场/系统新权限 | 由编辑机制推导 |
| 原主角状态阶梯 | 每 3 章推进一阶（看不起→疑惑→怀疑人生→绝望） | 原文规约第 3 条推导 |

## 5. 语言规范

- 系统操作用档案体（"【背景编辑】跟脚：凡人→王侯（消耗……）"），改动前后对比呈现。
- 原主角心理用碎裂短句（"不可能……他的师承明明是……"），信息差碾压靠台词外溢。
- 主角（反派）语言冷静缜密，话术像在下棋（"你以为的巧合，是我排了三十年的棋"）。
- 收割成功后配一段世界反应（众人重新站队），判定主角的字典里"真相即权势"。

## 6. 禁用套路（避坑清单）

- 纯恶反派（主角可以狠，不能low；虐杀无辜、欺男霸女是红线）。
- 编辑无代价无限制（每次编辑要有消耗/限制/风险，否则无紧张感）。
- 原主角降智（原主角必须按"聪明人被反复打脸"写，越强越显主角牛）。
- 背景升级无认证（无天地异象/无世界反应的编辑=自嗨）。
- 主角嘴炮解释自己穿越者身份（面对世界人物时，穿越是主角独享的秘密）。

## 7. 人物设定惯例

- 主角：穿越者+剧本知晓者，原剧情中的必死反派；靠信息差与编辑系统在死局里做活，杀伐果断但行事有逻辑。
- 系统："背景编辑系统"，功能是改写跟脚/师承/出身，有消耗与限制规则，偶尔毒舌拱火。
- 原主角（天命之子）：剧本钦定气运王，前期蔑视本主角，中期怀疑人生，后期不死不休。
- 被收割者：原主角的靠山/红颜/跟班，被背景编辑后成为主角的暗子，是"攻防线"的量尺。
- 围观阵营：圣地、古族、朝堂，谁的风向都跟着"背景认证"摇摆。
