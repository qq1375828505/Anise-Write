# 职业系统·超能力流

> 流派套件：tomato-genre ｜ 分类：urban ｜ 流派 ID：zhiye_xt
> 核心卖点：把普通职业变成超能力，法医、外卖员、快递员都能变强（细分领域蓝海）

## 1. 流派定位

职业系统流的爽感引擎是**职业行为的超凡化**：普通职业（法医、外卖员、快递员、保安、厨师）绑定系统，日常职业行为全部变成变强途径——送一单外卖变强、验一具尸体觉醒新能力。本流派是细分领域蓝海：用"最熟悉的陌生人职业"制造新鲜感（读者天天见外卖员，没见过外卖员肉身横渡禁区），职业细节的真实感提供代入，超凡问题的解决提供爽感。核心张力是"日常"与"超凡"的同框：主角可能刚送完宵夜，转头就用职业能力解决一件超凡大案。

## 2. 番茄原文规约（全文平移）

> 你是一位擅长职业系统流的网文作家。细分领域蓝海，核心公式：
> 1. 设定：普通职业（法医、外卖员、快递员）绑定系统，职业行为变强
> 2. 爽点：用职业特性解决超凡问题（法医能看见死者说话、外卖员送一单变强）
> 3. 节奏：每章1个职业任务+1次能力提升+1次意外收获
> 4. 描写重点：职业细节的真实感、能力觉醒的震撼、周围人的反应
> 5. 日常感：保持职业的日常属性，让读者有代入感

## 3. 写作技法清单

1. **职业细节写实**：职业流程必须真实（验尸报告怎么写、外卖箱怎么装、快递怎么分拣），真实感是超凡化的地基。
2. **行为即修炼**：把职业动作与系统奖励锁死（送一单=一次修为、破一案=一次觉醒），读者一看就懂的换算公式是流派标志。
3. **职业特性解题**：能力必须从职业里长出来（法医的"与死者对话"、外卖员的"极限送达"），禁止搬来与职业无关的技能库。
4. **三件套章构**：每章 1 个职业任务（引子）+ 1 次能力提升（中段）+ 1 次意外收获（收尾），结构恒定，爽感可预期。
5. **身边人反应**：同事、客户、围观者对"这人怎么越来越邪门"的渐疑曲线，是主角暴露程度的计数器。
6. **日常锚点**：再超凡的章也要回到工种日常（打卡、被投诉、躲监控），日常感是代入感的保险丝。

## 4. 节奏控制参数

| 参数 | 标准值 | 依据 |
| --- | --- | --- |
| 职业任务密度 | 每章 1 个 | 原文规约第 3 条 |
| 能力提升 | 每章 1 次 | 原文规约第 3 条 |
| 意外收获 | 每章 1 次 | 原文规约第 3 条 |
| 爽点密度 | 每章 ≥ 2（能力觉醒 + 意外收获/职业反差） | 原文规约第 3、4 条推导 |

| 章末钩子频率 | 每章 1 个：异常新订单/职业危机/系统新权限 | 由职业-超凡双线推导 |
| 日常锚点 | 每章 ≥ 1 处工种日常细节 | 原文规约第 5 条 |

## 5. 语言规范

- 职业语言要行话（法医的"尸斑""尸僵"，外卖的"超时""爆单"），行话密度=真实感。
- 系统提示绑定职业场景（"【职业行为：送达】获得……"），把系统嵌进职业流程。
- 觉醒瞬间用体感+环境双重描写（体温变化+旁人眼中的异常）。
- 主角与常人对话保持打工人口吻（对客户客气、对系统吐槽），超凡不外溢。

## 6. 禁用套路（避坑清单）

- 能力与职业脱钩（与职业无关的技能一律禁止，这是流派命根）。
- 职业流程失真（行业内行人一眼假=沉浸崩塌）。
- 主角早早公开身份（暴露度曲线要慢，普通人知情节奏以章为尺度推进）。
- 日常感丢失（连续超凡无日常的章节=读者代入感断电）。
- 系统直接给大礼包（一切奖励挂接职业行为）。

## 7. 人物设定惯例

- 主角：普通职业者（苦逼打工人人设），系统绑定前是行业老黄牛；强是系统+职业复利的产物，不是天赋爆炸。
- 系统：只认职业行为的"打卡机"，奖励与职业动作严格对价。
- 同事/客户：日常线群像，有人渐疑、有人抱大腿、有人举报，是主角社会生态。
- 超凡层：超凡事件的雇主/调查员/同类能力者，把职业线拉进大格局。
- 异常事件源：与系统奖励挂钩的任务池（异常订单、无名尸、禁区件），是剧情发条。
